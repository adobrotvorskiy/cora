# Провайдер `elevenlabs_agent` (WP15): один разговорный агент вместо каскада

> **Статус 21.09:** жёсткое расписание убрано (решение Сергея). Документ ниже описывает
> поведение в режиме `--start HH:MM`; без `--start` у хоста нет часов — толчок «открывай
> стендап» приходит не по 10:00, а когда люди просят её по имени («Кора, начинай»), дедлайны
> 10:28/10:30/10:35 не шлются вообще. Окна «бой только пн–чт 09:30–10:40» больше нет:
> `--live` разрешает боевую комнату в любое время.

Два живых теста 18.09 показали, что наш каскад (энергетический VAD → STT по фразам → LLM на каждое
событие → очередь реплик → TTS) ведёт себя «тупо»: отвечает на отдельные фразы, реплики копятся в
очереди и звучат без связи, быстрые правила («пауза → всё?», «≤ 2 человек → любой вопрос мой»)
срабатывают раньше мозга и спорят с ним, шум считается речью, галлюцинации STT получают ответ.
Сергей выбрал ElevenLabs Agents: **один связный агент слушает всю встречу, сам решает, говорить
или молчать, и сам говорит.** Наш код даёт только физику (Телемост, звук туда-обратно) и контекст
(кто на связи, кто говорит, сколько времени) и держит жёсткие границы (стоп-фразы, дедлайны при `--start`).

## 1. Что меняется

| | каскад (`openrouter`, `openai_realtime`) | агент (`elevenlabs_agent`) |
|---|---|---|
| слух | наш VAD + STT по фразам | ASR ElevenLabs (Scribe realtime) на непрерывном потоке |
| конец реплики | floor.js: closer / «всё?» / тишина | turn-модель ElevenLabs (`turn_v3`, `turn_eagerness: patient`) |
| решение говорить | brain (JSON-действие на каждый триггер) + правила в коде | LLM агента с системным инструментом `skip_turn` |
| речь | клипы + verbatim TTS через очередь | TTS агента, стрим PCM → тот же `Player` → страница |
| прерывание | barge-in по энергии в floor.js | событие `interruption` от сервера → `__host_flush` ≤ 50 мс |
| очередь спикеров | state.plan в коде | у агента в голове; наш код только записывает `give_word`/`turn_done` |
| контекст | снимок JSON в каждом вызове мозга | `contextual_update` (кто говорит, кто пришёл/ушёл, время) + `user_message`-«толчки» на таймерах |
| kill switch | guards.js | тот же guards.js: стоп-фраза из `user_transcript`, файл `state/STOP` — она выходит из звонка; плюс 10:35, `--max-minutes` |

Каскад остаётся рабочим провайдером: `settings.voice.provider = "openrouter"` (по умолчанию). Агент включается
`"elevenlabs_agent"` в `config/settings.local.json` или флагом `--provider elevenlabs_agent` (`src/main.js`,
`tools/run_testroom.js`).

## 3. Протокол ElevenLabs (сверено с OpenAPI 18.09.2026)

- WS `wss://api.elevenlabs.io/v1/convai/conversation?agent_id=…`. Агент приватный (`platform_settings.auth.enable_auth: true`),
  поэтому URL берём подписанный: `GET /v1/convai/conversation/get-signed-url?agent_id=…` с `xi-api-key` → `{signed_url}`.
- Первое сообщение клиента: `{"type":"conversation_initiation_client_data","conversation_config_override":{"agent":{"prompt":{"prompt":…},"first_message":"","language":"ru"}},"dynamic_variables":{…}}`.
  Переопределения должны быть разрешены в `platform_settings.overrides.conversation_config_override` (prompt, first_message, language).
- Сервер отвечает `conversation_initiation_metadata` (`conversation_id`, `agent_output_audio_format`, `user_input_audio_format`).
  Оба формата задаём `pcm_24000` (наша страница и плеер работают на 24 кГц); если сервер вернул другое — линейный ресемплер.
- Клиент → сервер: `{"user_audio_chunk":"<b64 pcm16>"}` (100 мс чанки страницы как есть), `{"type":"contextual_update","text"}`
  (фоновый контекст, не вызывает ответ), `{"type":"user_message","text"}` (как реплика пользователя: вызывает ход агента),
  `{"type":"pong","event_id"}`, `{"type":"client_tool_result","tool_call_id","result","is_error"}`.
- Сервер → клиент: `audio {audio_event:{audio_base_64,event_id}}`, `agent_response {agent_response_event:{agent_response,event_id}}`,
  `agent_response_correction`, `agent_response_complete`, `user_transcript {user_transcription_event:{user_transcript}}`,
  `tentative_user_transcript`, `interruption {interruption_event:{event_id}}`, `ping {ping_event:{event_id,ping_ms}}`,
  `client_tool_call {client_tool_call:{tool_name,tool_call_id,parameters,expects_response}}`, `vad_score`, `client_error`.
  Как в SDK: после `interruption` с `event_id = X` аудио с `event_id ≤ X` отбрасываем.
- Системные инструменты: `prompt.built_in_tools.skip_turn = {type:"system", name:"skip_turn", params:{system_tool_type:"skip_turn"}}`
  (агент молчит на этом ходу), `end_call` (сервер завершает разговор после реплики).
- Client tools создаются отдельно (`POST /v1/convai/tools`, `tool_config.type = "client"`, `parameters` = JSON-schema объекта,
  `expects_response: true`) и подключаются к агенту через `prompt.tool_ids` (inline `prompt.tools` объявлены устаревшими).
- Turn: `turn.turn_eagerness: "patient"`, `turn.turn_timeout` (сколько ждать тишины, прежде чем дать агенту ход; 1–30 с),
  `interruption_ignore_terms` («угу», «ага», «да-да» не перебивают Кору).
- Разговор: `conversation.max_duration_seconds` (по умолчанию 600! ставим 2700), `client_events` — какие события шлёт сервер.
- Стоимость: `GET /v1/convai/conversations/{id}` → `metadata.cost` (кредиты), `metadata.charging.llm_charge/call_charge`,
  `call_duration_secs`; баланс — `GET /v1/user/subscription` (`character_count`/`character_limit`). Free: 10 000 кредитов ≈ 15 мин
  агента в месяц (≈ 667 кредитов/мин); платные тарифы ≈ $0,08/мин + LLM.

## 4. Промпт агента (`buildAgentPrompt`)

Два режима (`voice.eleven.prompt_mode`). **`compact` (по умолчанию, §8):** кто ты → как ты слышишь → молчание и речь →
как говорить (точные наборы подтверждений/передач, запрещённые оценки) → стендап (тема дня с приветствием и прощанием дня,
Орлов, финал, расписание) → участники (`id: короткое имя (полное), роль`; `{{present}}`, `{{lead_status}}`) → инструменты →
границы + 4 FAQ. **`full`:** то же плюс блок «Промпт-блок» из `persona.md` (`{brain_model}` подставлен, строки про стек OpenAI
заменены на ElevenLabs) и `playbook.md` целиком (без секции про действия каскада) и примеры. Значения `{{…}}` приходят как
`dynamic_variables`, а хост дополнительно шлёт готовый промпт в `conversation_config_override` (файлы перечитываются при каждом
запуске, без пересоздания агента).

Правила молчания и речи (главное, чем лечим «отвечает на отдельные фразы»):
- `skip_turn` — действие по умолчанию. Говорить только когда: хост сообщил 10:00 (открыть стендап); спикер явно закончил
  («у меня всё», «как-то так», «передаю») → одна реплика слушателя + следующее имя; к ней обратились по имени
  (Кора/Кара/Корра/Карат/ведущая); пауза после апдейта затянулась и она не уверена → «Тима, всё?» один раз; хост попросил завершить.
- Вопросы внутри чужого апдейта адресованы команде, а не ей. Разговоры коллег между собой не комментировать; > минуты и не про
  стендап — мягко предложить дев-синк. Шум, обрывки, бессмыслицу в транскрипте игнорировать.
- Одна реплика — одна мысль, ≤ 2 предложений, без пересказов и итогов; активное слушание — короткая фраза, не повтор.
- Кто говорит — только из заметок хоста «Говорит: Тима»; иначе не называть наугад.
- «Ты», женский род, короткие имена: Слава, Глеб, Тима, Серёжа, Кир, Савва, Игнат, Митя.

Client tools (агент вызывает, хост исполняет и отвечает строкой):
`give_word{person_id}` (передала слово), `turn_done{person_id}` (человек закончил; ответ хоста перечисляет, кто ещё не выступал),
`set_phase{phase: waiting|round|open_floor|closing}`, `leave_meeting{}` (после прощания и передачи слова на дев-синк; так же завершаешь, если просят уйти).
Плюс системные `skip_turn` и `end_call`.

## 5. Хост в режиме агента (`agent_host.js`)

1. Старт: `guards` (STOP-файл, таймеры), Chrome, аудиоадаптер страницы + аватар, `Player`, вход в Телемост, наблюдатели DOM.
2. Агент подключается в `times.start − eleven.connect_before_start_s` (09:59:30) или сразу, если уже позже; закрывается сразу
   после прощания/выхода — платим только за нужные минуты.
3. Звук страницы (микс удалённых треков, 100 мс) → `agent.pushAudio` без обработки. Аудио агента → `attachPlayer` → `Player` →
   `__host_play`; `interruption` → `Player.stop` → `__host_flush` (≤ 50 мс на странице). Эхо невозможно: наш микрофон не входит в микс.
4. Контекст → агент (`contextual_update`, дедуп + троттлинг): `[хост HH:MM:SS] Подключился Тима. На связи: Слава, Глеб, Тима.
   Слава Орлов: на связи.`; `Говорит: Тима.` при смене активного спикера по DOM (≥ 2 с между обновлениями); 10:28 «ускоряйся».
   Толчки (`user_message`, вызывают ход агента): 10:00 «открывай стендап» (+ статус Орлова и список на связи), 10:02 «Славы
   нет, реши про старт без него» (только если круг не начался), 10:30 «завершай», `--max-minutes` «попрощайся и вызови leave_meeting».
5. Client tools: `give_word` → текущий спикер (для атрибуции строк транскрипта и обновлений), `turn_done` → выступил,
   `set_phase`, `leave_meeting` → подождать начала прощального аудио (≤ 6 с) и его конца (≤ 15 с) → закрыть агента → `leave` → выход.
   `end_call` агента = закрытие WS сервером → тот же выход. Неожиданный обрыв WS → новый разговор (до 3 попыток, 1/2/4 с) с
   заметкой-резюме (фаза, кто выступил, кто говорит).
6. Границы (код, не LLM): «Кора, стоп» в `user_transcript`/`tentative_user_transcript` → немедленный обрыв реплики и тихий режим (слушает, не говорит; возврат по обращению по имени); стоп-фраза выхода
   («Кора, уйди из встречи» + варианты имени, «мы сами», «дальше без тебя») → немедленно flush + закрыть агента + выход из звонка; `state/STOP` → то же; 10:35 → выход без фраз;
   `--max-minutes` → толчок «попрощайся» и через 45 с выход в любом случае; Ctrl+C → выход. Прямое обращение по имени с ответом `skip_turn` → нудж «ответь» (`host.addressed_skip`):
   молчать на обращение недопустимо, детерминированно, не надеясь на промпт.
7. Логи (`logs/*.jsonl`): `agent.connect/metadata/context/nudge/nudge_deferred/nudge_dropped/transcript/tentative/response/correction/interruption/
   speech.start|end|abort/tool_call/tool_result/close/reconnect/error`, `guard.*`, `host.kill_leave`, `cost.summary`
   (минуты соединения, оценка кредитов, фактический `cost` разговора и баланс до/после). Аудио агента пишется в
   `_internal/eleven_agent_<дата>_<время>.wav` (`voice.eleven.record_audio: agent|both|none`).

## 6. Риски и как они закрыты

| Риск | Чем лечим |
|---|---|
| групповой разговор: транскрипт без имён, агент отвечает не тому | заметки «Говорит: …» из DOM-индикатора; правило «не называть наугад»; `give_word` фиксирует ожидаемого спикера |
| кросс-ток и «угу» перебивают Кору | `interruption_ignore_terms`; её реплики короткие; после `interruption` она замолкает сразу (flush) и не извиняется |
| побочные разговоры, риторические вопросы внутри апдейта | правила skip_turn + примеры в промпте; `turn_eagerness: patient` |
| шум/галлюцинации ASR | Scribe + turn_v3 вместо энергетического VAD; правило «бессмыслицу игнорировать» |
| агент заговорит до 10:00 или на таймауте тишины | `first_message: ""`; правило «до 10:00 skip_turn»; `turn_timeout` 20 с |
| free-тариф: 15 мин/мес | подключение за 30 с до старта, закрытие после прощания; smoke ≤ 2 мин; полный стендап только после апгрейда |
| промпт устареет | хост шлёт override промпта из актуальных persona/playbook при каждом запуске |

## 8. После первого живого теста (19.09, Серёжа + Нина): латентность

Вердикт: «уже очень сильно, но долго ждать ответ». Измерено: конец речи (DOM) → транскрипт 0,4–1,6 с (turn-модель `patient`),
транскрипт → первое аудио 0,0–0,3 с, кроме передачи слова: `turn_done` → ответ хоста → второй шаг LLM → +1,3 с. Изменения:

| Что | Было | Стало | Компромисс |
|---|---|---|---|
| client tools | `expects_response: true` (модель ждёт ответ хоста) | **не блокирующие** (`expects_response: false`); состояние ростера модель получает заметкой `[хост] Слово у: Тима. Ещё не выступали: …` | модель не узнает об ошибке инструмента; хост сам ведёт учёт |
| `turn_eagerness` | `patient` | **`normal`** (`voice.eleven.turn_eagerness`) | `patient` — меньше ложных концов реплики, но +0,5–1 с до её реплики; `eager` — быстрее всего, больше вклиниваний. Говорить или молчать всё равно решает модель (`skip_turn`) |
| LLM | `gemini-3.5-flash` | **`gemini-3.5-flash-lite`**, reasoning `minimal`, temperature 0,3 (бенч 18.09 на той же задаче: TTFT медиана 967 мс против 1372 у Gemini 3 Flash, решения 68/68 валидны) | fallback `gemini-3.5-flash` одной строкой в `voice.eleven_llm`, если Lite станет нарушать правила |
| промпт | persona.md + playbook.md + правила ≈ 17,4k символов (≈ 5k токенов) | **компактный** (`prompt_mode: compact`): личность, слух, правила молчания/речи, точные наборы подтверждений и передач, запрет оценок, Орлов, финал, границы + 4 коротких FAQ ≈ 4,9k символов ≈ **1,45k токенов** (оценка; точное число — событие `context_usage` в логе `agent.context_usage`) | `prompt_mode: full` остаётся для A/B |
| оценки | «Отличный план на неделю, Нина!» | в промпте: запрещённые слова (отличный, классный, здорово, приятные, круто, супер, молодец, интересно, …) и единственно допустимые подтверждения «Поняла, спасибо, {имя}.» / «Спасибо, {имя}!» / «Принято, {имя}.», передачи «Дальше {имя}.» / «{имя}, тебе слово.» | — |
| гости | `give_word(vera)` → ошибка | `person_name` в `give_word`/`turn_done`: гость регистрируется под `guest_*`, логируется `agent.guest` | — |
| метрика | — | `agent.turn_latency {turn_ms, since_transcript_ms}` на каждую реплику: конец речи в комнате (уровни микса страницы: шумовой пол + 12 дБ) → первый чанк аудио агента; в `cost.summary` `turn_latency_ms {n, p50, p90, max, since_transcript_p50/p90}` | — |
| захват | чанки 100 мс | **50 мс** (`voice.eleven.chunk_ms`): ASR получает звук раньше, конец речи точнее; 20 сообщений/с вместо 10 | — |

## 8a. После второго живого теста (19.09, Серёжа + Нина): старт и финал

Задержка стала нормальной: p50 323 мс. Вердикт: «огромные проблемы с тем, чтобы начать и корректно закончить. В начале она не может задрайвить встречу и много молчит. В конце она хватается за первую возможность завершить и быстро сваливает». По логу:
- до 10:00 и после ставила `skip_turn` на «Чего молчим? Кого ждём?», «Может, начнём?», «Алё! Меня слышно?» и даже «Он мне написал, что не придёт», потому что промпт разрешал речь только в пяти перечисленных случаях;
- вопрос открытого слова перебили на «Все…»; она его не повторила и не ответила на «Кора, извини, перебил тебя», а на «Короче, всё сказали» сразу попрощалась;
- после `leave_meeting` в том же ответе договорила «нельзя передавать слова после завершения стендапа».

Сергей: «чем жестче логика — тем тупее бот». Поэтому поведение задаётся принципами в промпте, а хост сообщает только факты и держит безопасность.

| Что | Было | Стало |
|---|---|---|
| когда говорить | «По умолчанию молчишь… только в пяти случаях» | принцип **«у кого слово»**: слово у человека — молчит, если только он не закончил, к ней не обратились или хост не сообщил о тишине; слово ни у кого (до старта, между людьми, в конце) — встречу ведёт она и отвечает на всё про встречу без обращения по имени (`whenToSpeakSection`, общий для compact и full) |
| старт | молчать до заметки 10:00; ждать до 10:02 | в 10:00 открывает; решают люди: предложили начать или сказали, что Слава не придёт, — начинает сразу; иначе в 10:02 «никто не против?». Агент подключается с 09:58 (`connect_before_start_s` 120), чтобы отвечать до старта; долгая пауза, ждать никто не договаривался — можно разрядить лёгкой репликой |
| финал | закрыть по тишине 6 с (модель её не измеряет) | без вопроса «кто что добавит» не прощается, оборванный вопрос повторяет; на добавку — «Принято. Кто-то ещё?»; прощается по тишине после своего вопроса или по явному «нет / закругляемся»; прощание своими словами («Всё, ребята, хорошей недели! Дальше дев-синк, пока!») |
| время | модель не знает, сколько длится тишина | заметка-факт **«Тишина N с после …»** (user message): 7 с в круге и на открытом слове, 5 с когда слово ни у кого, 6 с после её «никто не против?», 20 с на пустой паузе до старта (один раз); не больше двух подряд без человеческой речи или смены слова (`voice.eleven.silence_s`, `silence_nudges_max`). Что значит тишина, решает модель |
| Орлов | заметка о подключении (без хода) | ждали, а он пришёл — заметка с ходом («Стендап ещё не начат, его ждали»); посреди круга — заметка «ещё не выступал» |
| молчаливый спикер | передача слова дальше помечала его «выступил» | не звучал после передачи — остаётся в «Ещё не выступали» («вернусь к тебе в конце») |
| прощание | уходила сразу, договаривала после `leave_meeting` | **пломба**: в комнату идёт только текст до `leave_meeting` (срез по посимвольному `alignment` аудио ElevenLabs, без него по оценке длины, мс на символ меряются в сессии), позже начатые ответы отбрасываются; после прощания 5 с тишины (`leave_linger_ms`); перебили прощание, обратились по имени или сказали «подожди» — остаётся (один раз, после 10:30 уже нет); `пока` и `до завтра` в `interruption_ignore_terms` |
| подтверждения | «строго одна фраза из набора» | фразы слушателя как примеры; запрет похвалы и пересказа остаётся |

Лог: `agent.nudge {kind: silence | lead_joined}`, `host.farewell_seal / farewell_extra / farewell_pending`, `agent.speech.seal / sealed / cut`, `host.leave_canceled`, `agent.alignment_sample` (первые 3 чанка с разметкой: проверить, относительные ли времена); в `cost.summary`: `silence_nudges`, `leave_cancels`, `farewell`, `speech_ms_per_char`, `playback.sealed_drop_ms`.
