# standup-host — ИИ-ведущая утреннего стендапа

Бот сам заходит в Телемост на стендап команды (пн–чт 10:00–10:30 МСК, постоянная комната) и ведёт его женским голосом. Ждёт Ярослава Орлова и первым даёт слово ему, дальше по очереди остальным. В понедельник спрашивает фокусы на неделю, во вторник–четверг планы на день. В конце открывает слово для вопросов, желает хорошей недели или хорошего дня, передаёт слово на дев-синк и выходит. Устройство: один Node-процесс, страница Телемоста под `playwright-core` (Chrome), OpenAI Realtime (уши и голос `shimmer`), мозг на OpenRouter/OpenAI, жёсткие правила (guardrails) в коде. Архитектура, решения и пакеты работ описаны в [PLAN.md](PLAN.md).

> Статус: ядро (WP6) подключено — хост заходит в комнату и ведёт стендап. Устройство ядра: [docs/core.md](docs/core.md). Боевая комната открывается только флагом `--live`; тесты — `tools/run_testroom.js` в тест-комнате. Расписание у хоста необязательное (см. `--start` ниже): без него таймеров нет — она входит сразу и открывает стендап, когда её просят по имени.

## Требования

- Windows 11, Node.js ≥ 24, установленный Google Chrome (канал `chrome`; браузеры Playwright не скачиваются).
- `npm install` в этой папке (зависимости: `playwright-core`, `ws`, для SpeechKit — `@grpc/grpc-js` и `@grpc/proto-loader`).
- Ключи лежат в корне репозитория, в `.env.personal` и `.env.local`. Приоритет: переменная окружения, потом `.env.personal`, потом `.env.local`.
  - `OPENAI_API_KEY` нужен только при `voice.provider = "openai_realtime"` (Realtime API); при провайдере `openrouter` `--check` его не требует;
  - `Cora_KEY` (`.env.personal`, ключ OpenRouter Коры; имя задаётся в `settings.keys.openrouter`) — мозг (`google/gemini-3.5-flash-lite`) и голос/слух (`openai/gpt-audio-mini`, `openai/gpt-4o-transcribe`) через OpenRouter;
  - `key` (`.env.local`, секция «Яндекс студия комайнд»; имя в `settings.keys.yandex`) — API-ключ Yandex Cloud для провайдеров `yandex_cascade` и `yandex_rt`; каталог облака — `yandex.folder` в `settings.local.json`;
  - `TELEGRAM_BOT_TOKEN` нужен для алертов в Telegram (необязателен).

## Запуск

```powershell
cd C:\Users\aleks\template\scripts\standup_host
npm run check    # = node src/main.js --check; всё готово, если последняя строка "RESULT OK"
npm test         # юнит-тесты
```

`--check` печатает по ключам только present/absent, а ещё провайдера мозга, найденный Chrome, сводку настроек и режим дня. Результат пишется строкой `check` в лог. Код выхода 0 значит «готово».

**Ручной запуск** (из видимого окна PowerShell): перед входом `npm run check`, затем `.\run-standup.ps1 --verbose` (или `node src/main.js --verbose`). Два режима:

- **По требованию** (без `--start`, основной): у хоста нет часов. Она заходит сразу, отвечает людям, а стендап открывает, когда её просят по имени («Кора, начинай», «Кора, поехали»). Дедлайнов нет: ведёт, пока не попросили уйти / Ctrl+C / `--max-minutes`.
- **С расписанием**: `--start 10:00` — как раньше: голос подключается за 2 минуты до старта, нудж «Пора открывать стендап» в 10:00, «Орлов не подключился» в 10:02, ускорение 10:28, финал 10:30, принудительный выход 10:35. Любое другое время: `--start 11:30` сдвинет все отметки (дедлайны — со смещениями из `settings.times`).

Без `--live` хост откажется входить в боевую комнату (в тестовую — можно всегда). Планировщик (`register-task.ps1`, WP9) включаем позже и только с OK.

| Флаг | Что делает |
|---|---|
| `--check` | проверка готовности (см. выше) |
| `--shadow` | зайти, слушать и писать лог, но молчать |
| `--url <url>` | другая комната (например, тестовая) вместо `meeting_url` |
| `--at HH:MM` | симуляция часов: будто сейчас HH:MM сегодня (МСК), дальше время идёт как обычно |
| `--day mon\|tue\|wed\|thu` | симуляция дня недели (пн: фокусы на неделю, вт–чт: планы на день) |
| `--start HH:MM` | расписание: стендап стартует в HH:MM, дедлайны сдвигаются. Без флага — режим «по требованию»: таймеров нет, открывает по просьбе по имени |
| `--verbose`, `-v` | дублировать события лога в консоль |
| `--no-brain` | без вызовов LLM-мозга: скриптовый сценарий (старт с Орловым / без, очередь по ростеру, open floor, прощание) |
| `--live` | разрешить боевую комнату (в любое время; окна «пн–чт 09:30–10:40» больше нет) |
| `--max-minutes <n>` | попрощаться и выйти через n минут после запуска (тесты; считается от запуска, не от старта круга) |
| `--no-alert` | не слать алерты в Telegram (тесты) |

Тестовый прогон: `node tools/run_testroom.js --at 09:59 --day mon --max-minutes 4` (лента событий в консоли) или `node src/main.js --url <ссылка на тест-комнату> --at 09:58 --day mon --verbose --no-alert --max-minutes 4`.

**Провайдер `yandex_cascade`** (26.09, весь конвейер на Яндексе): уши — SpeechKit STT v3 (gRPC), отдельная сессия распознавания на каждый аудиослот Телемоста; мозг — Yandex AI Studio (`brain.yandex_model`, по умолчанию `aliceai-llm-flash/latest`: на бенчмарке 26.09 5/5 верных решений, p50 1,2 с; YandexGPT Lite — 2/5, 1,7 с); рот — SpeechKit TTS v3 (`yandex.tts`: голос `alena`, роль `good`, скорость 1.1). Мозг отвечает JSON-действием, в эфир уходит только его поле `text`, поэтому зачитать служебный текст она не может по построению. Включение: `--provider yandex_cascade` или `{"voice":{"provider":"yandex_cascade"}}` в `settings.local.json` (там же `yandex.folder`). Живая проверка без комнаты: `node tools/yandex_cascade_probe.js` (синтез двух фраз, их распознавание по двум дорожкам сразу, одно решение мозга). Smoke: `node tools/run_testroom.js --provider yandex_cascade --max-minutes 3`. Бенчмарк мозга: `node tools/bench_brain.js --provider yandex`.
- Телемост отдаёт звук комнаты через SFU-слоты: на стендапе 23.09 при шести участниках было 2 аудиодорожки. Слот — не человек, поэтому имя говорящего берётся из подсветки плитки в DOM на интервале фразы; если подсвечены двое, выбирается тот, чья подсветка совпадает с громкостью именно этого слота (`attribution.speakerForTrack`). Два громких слота дольше 0,6 с — заметка мозгу `chorus` («говорят одновременно»).
- Страница шлёт дорожку слота только пока в ней звук (плюс 100 мс до и 300 мс после), после фразы уши досылают 1,5 с нулевого PCM: детектор конца фразы SpeechKit (`HIGH`, подсказка паузы 500 мс) закрывает фразу через ~0,9 с. `silence_chunk` детектор игнорирует (замер 26.09).
- Когда говорить, каскад решает по распознанной речи, а не по громкости (`floor.activity: 'speech'`, живой тест 26.09: домашний фон держал её молчащей): комната «занята» от первой частичной гипотезы до финала фразы, её собственное эхо (≥60% слов из её недавних реплик) не считается. Перебить её может только распознанная речь: 2+ слова не из её реплики или «подожди/стоп». На обращение по имени она отвечает не позже чем через 2 с, даже если комната не затихла.
- Промпт мозга зависит от режима: без `--start` в нём нет ни часов, ни «ждём Ярослава до 10:02» — в `config/playbook.md` разделы «Старт» и «Время» есть в вариантах `[по расписанию]` и `[по требованию]`, в промпт попадает один. Живая проверка решений мозга без расписания: `node tools/brain_on_demand_probe.js`.
- Подсветка говорящего (`rootStroke_*` на плитке) с обновления Телемоста 21.09 живёт в iframe звонка; до 26.09 наблюдатель (`telemost.installObservers`) смотрел в главный документ и не видел ни одной подсветки. Теперь он ставится в iframe и переустанавливается, если iframe сменился.
- Голос ElevenLabs («Настя») вместо SpeechKit: `"yandex": {"cascade_mouth": "elevenlabs"}`.

**Провайдер `elevenlabs_agent`** (WP15, [docs/eleven_agent.md](docs/eleven_agent.md)): вместо каскада один разговорный агент ElevenLabs слушает всю встречу, сам решает, когда говорить (`skip_turn`), и говорит голосом Nastya; хост даёт только Телемост, звук и контекст. Ключ `Elevenlabs_Cora_API` (`.env.personal`, имя в `settings.keys.elevenlabs`). Агент создаётся один раз: `node tools/eleven_agent_setup.js` (id пишется в `settings.voice.eleven_agent_id`; повторный запуск обновляет промпт и инструменты). Включение: флаг `--provider elevenlabs_agent` (`src/main.js`, `tools/run_testroom.js`) или `{"voice":{"provider":"elevenlabs_agent"}}` в `settings.local.json`. Smoke: `node tools/run_testroom.js --provider elevenlabs_agent --at 09:59 --day mon --max-minutes 2`. Free-тариф ElevenLabs: 10 000 кредитов ≈ 10–15 минут живого разговора в месяц (после второго живого теста 19.09 осталось 4 515), поэтому полный стендап требует платного тарифа.

Как ведёт агент (после теста 19.09, где она молчала до 10:00 и спешила закрыться). Решения принимает модель по принципам промпта: у кого слово, старт по решению людей, неспешный финал, прощание своими словами. Хост не решает, кому говорить, он только сообщает факты, которых модель сама не знает:
- время и отметки расписания — только в режиме `--start` (10:00, 10:02, 10:28, 10:30); в режиме по требованию время не шлём, а просьбу «Кора, начинай» хост подхватывает сам и присылает как поручение открыть стендап;
- кто вошёл и кто говорит;
- тишину: «Тишина 7 с после …» в круге и на открытом слове, 6 с после её «никто не против?», 20 с на пустой паузе до старта, не больше двух таких заметок подряд;
- что подключился Орлов, которого ждут.

Прощание запечатано: в комнату попадает только сказанное до `leave_meeting`, хвост режется по посимвольной разметке ElevenLabs, а без неё по оценке длины. После прощания 5 с паузы; если в это время к ней обратились или сказали «подожди», она остаётся (один раз, после 10:30 уже нет). Агент подключается с 09:58 (`connect_before_start_s`: 120), чтобы отвечать людям до старта.

## Данные людей и компании

Ростер, персона, плейбук, фразы, исправления распознавания и ссылки на комнаты — данные команды: они лежат только локально (`.gitignore`), в репозитории — выдуманные примеры `config/*.example.*`, которые код берёт, если локального файла нет. Чтобы запустить на своей команде, скопируйте примеры без `.example` и заполните; ссылки на встречи, чат алертов и id каталога Yandex Cloud — в `config/settings.local.json`. Подробности — в [CLAUDE.md](CLAUDE.md).

## Настройки

`config/settings.json` хранит значения по умолчанию. Имена ключей — контракт между модулями, их не переименовываем. Локальные правки кладите в `config/settings.local.json` (файл необязателен и в git не попадает): он накладывается поверх через deep merge, например `{"meeting_url": "https://telemost.yandex.ru/j/…"}`. Порядок наложения: `settings.json`, затем `settings.local.json`, затем флаги CLI. Голос `shimmer` идёт на скорости API 1.0, темп речи задаётся только текстом `realtime.pace_instructions`.

## Безопасность

- Ключи читает только процесс Node. Наружу (в консоль, в `--check`, в логи) попадает только present/absent. Значения секретных переменных в логах дополнительно маскируются.
- Без голоса в бой не входим: в боевую комнату (`--live`, не `--shadow`) хост не входит, если голос не подключился или не настроен — запуск завершается с ошибкой до join и уходит алерт в Telegram (в тестовой комнате деградирует в глухонемый режим как раньше).
- В `logs/standup_YYYY-MM-DD.jsonl` лежат транскрипты встречи: храним только локально, не коммитим и никому не пересылаем. `logs/`, `cache/`, `state/`, `profile/` (профиль Chrome бота) и `_internal/` добавлены в `.gitignore`.

## Kill switch

Два уровня, оба срабатывают за ~1 с, в обход очереди событий:

1. **«Кора, стоп»** (варианты: хватит / замолчи / тихо) — она прерывает реплику и **молчит, оставаясь в звонке**: слушает, транскрипты идут, таймеры подавлены. Возвращается к ведению, когда к ней обратятся по имени («Кора, продолжай»).
2. **«Кора, уйди из встречи»** (варианты: уходи / выйди / выходи / покинь встречу) — она **выходит из звонка** за ~1–2 с, процесс завершается. «Мы сами», «дальше без тебя» рядом с именем — тоже выход.
3. Файл `state/STOP` (его создаёт `stop-standup.ps1`, или вручную: `New-Item state\STOP`) — то же, что п.2: выход из встречи.
4. Ctrl+C в консоли. Процесс завершается, бот выходит из звонка.
